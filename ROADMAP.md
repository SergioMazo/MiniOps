# Roadmap

## 0.1.x — Safe foundations

- Validate conservative installation and rollback behavior
- Expand unit tests for configuration edge cases
- Exercise Ubuntu and Debian in clean CI environments
- Improve status snapshots without widening secret access

## 0.2.0 — Operational maturity

- Package-oriented installation and signed release artifacts
- Optional notification adapters with explicit secret boundaries
- Structured status output for external monitoring
- More complete SFTP server-side reference configuration
- Automated upgrade and migration checks

## Later

- Additional tested distributions
- Rootless backup patterns where Restic source permissions allow them
- UPS and hardware power-event integrations
- Reproducible integration-test images

Roadmap items are intentions, not commitments.
