# Support

MiniOps is a community project and does not provide an availability or
response-time guarantee.

Use:

- a bug issue for reproducible defects;
- a documentation issue for unclear or incorrect instructions;
- a feature request for a concrete, general-purpose improvement.

Include the MiniOps version, distribution, relevant sanitized command output,
and the exact dry-run or test command. Never post credentials, private keys,
real repository addresses, or unredacted logs.

Security issues must follow [SECURITY.md](SECURITY.md).
